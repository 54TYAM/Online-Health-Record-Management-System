# 🩺 Online Health Record Management System

A MERN Stack project to digitize and manage hospital patient records securely.

<img width="1536" height="1024" alt="Thumbnail of MediCare GitHub" src="https://github.com/user-attachments/assets/e754fd47-f0cb-4009-a2cc-345fcef1d6c1" />

## 🧠 Tech Stack
- React.js (Frontend)
- Node.js + Express.js (Backend)
- MongoDB (Database)
- JWT Authentication
- Tailwind CSS for styling

## 🚀 Features
- Patient/Doctor/Admin Login
- Appointment Booking
- Record Upload and Management
- Secure Role-based Access

## 📦 Setup
```bash
# Run backend
cd backend
npm install
npm start

# Run frontend
cd frontend
npm install
npm start
